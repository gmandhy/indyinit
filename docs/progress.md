- `src/lib/acousticTap.ts` implements browser-independent continuous DSP with a sample-count sliding ~10 ms RMS window, handling actual sample rates and arbitrary nonempty block lengths. The **onset's first threshold-crossing sample time** is the event timestamp; the subsequent rolling-window peak is the event amplitude.
